# _files 清单：集合一致、顺序不同（哈希差异的精确说明）

> 2026-10-13 ｜ 涉及 `speech_near_train70_files.txt` / `speech_far_train70_files.txt`
> 起因：t12 回报里"顺序也未变"的结论与实测不符；本文件给出可自查的精确差异，避免
> "同一个集合却有两个 sha256"在收档/复现时引起误判。

## 结论

| 项 | t11 训练侧临时版（train-eng 原稿） | t17 正式版（仓内 / 服务器） |
|---|---|---|
| near 行数 / 字节 | 3477 / 138120 | 3477 / 138120 |
| far 行数 / 字节 | 3675 / 146008 | 3675 / 146008 |
| 集合 | 完全相同 | 完全相同 |
| 行尾 | LF | LF |
| **行序** | **全局字典序**（实测 `lines == sorted(lines)` 为 True） | `reader 清单顺序 × reader 内文件名升序` |
| near sha256 前缀 | `456e5442d2a71314` | `1d20d55633075f56` |
| far sha256 前缀 | `e7db5e0a76034910` | `82a475cd7e1e97b0` |
| **排序后 sha256** | `456e5442…` / `e7db5e0a…` | **与之分别相等**（实测） |

**收档标准表述（队长 2026-10-13 裁定，t14 可直接引用）**：

> **在训 run = 临时版哈希为准**（t12 NN-AEC，08:10 UTC 启动；near `456e5442…` / far `e7db5e0a…`），
> 不中断重启——集合等价已证、顺序对 DM 随机采样无影响；
> **后续 run = 正式版哈希**（DCCRN/级联等；near `1d20d556…` / far `82a475cd…`）；
> 两者**集合等价证据 = `sort` 后 `sha256` 相等**（near 均为 `456e5442…`、far 均为 `e7db5e0a…`，实测相等）。

**只有顺序不同**：两份文件**字节数相同**（故"行尾风格差异"不能解释 sha256 不同），
逐行比较在第 0 行即分叉：

```
临时版 line 0 = book_00002_chp_0005_reader_11980_0.wav
正式版 line 0 = book_01279_chp_0009_reader_03013_0.wav
```

（顺带：临时版即"全局字典序"，故其**原始 sha256 恰好等于排序后 sha256**；正式版不是全局字典序，
故两者原始哈希不同、排序后哈希相同——这正好解释了"为何一个哈希像另一个的 sort 版"。）

## 为什么会不同（不影响数据语义）

- 正式版顺序由生成器规则写死（`scripts/build_speech_file_lists.py`），**可重算、幂等**。
- 临时版的顺序来自 train-eng 当时的展开方式，**实测为全局字典序**（`sorted(lines)`）——
  与正式版的"reader 清单顺序 × reader 内文件名升序"是不同的两种枚举序；**同名集不同排列**。
- 对训练**无影响**：DM 入口 `build_pools(池目录, 文件名清单)` 按集合取数，行序不参与语义。

## 对复现/收档的影响（需要注意的一点）

t11 的 run manifest 里钉的是**启动时刻**的 `456e5442…/e7db5e0a…`；t17 正式版是
`1d20d556…/82a475cd…`。**同一个名单集合、两个文件哈希**——所以：

- 复核 t11 那次 run 时，请以 manifest 里记录的哈希为准（那是当时真实的输入字节）；
- 引用"t17 正式版"时用 `speech_nearfar_train_meta.json` 的 `file_lists.sha256`；
- 两者**不可互相替代做字节比对**，但可用"集合相等 + 逐行内容相等（排序后）"互证。

## 自查命令（任意一端可跑）

```bash
# 集合与内容一致、仅顺序不同：排序后应完全相同
sort speech_near_train70_files.txt | sha256sum          # 临时版排序后再算
sort <正式版>/speech_near_train70_files.txt | sha256sum # 两值应相等
# 或
python - <<'PY'
a = [l for l in open("临时版").read().splitlines() if l]
b = [l for l in open("正式版").read().splitlines() if l]
assert set(a) == set(b), "集合不同！"
print("集合相同；顺序相同：", a == b)
PY
```
