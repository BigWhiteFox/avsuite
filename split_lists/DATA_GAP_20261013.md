- 双端（本机与服务器）到 openslr 均只有 **22–35 KB/s**；本机测过的镜像同样不可用：
  aliyun `404`、tuna `403`、ustc `404`、bjtu 不可达、hf-mirror 对应 repo 无 tar/zip 形态。
- 服务器出网聚合上限 **~111 KB/s**，6 路并发拉同一文件聚合仅 83 KB/s（**0.40×，不扩展**）⇒ 国际链路限速，

- 因此"服务器下载"与"本机下载后推送"两条路都不通，非单侧问题。

## 3. 互斥核对（硬约束，已实测）

用 `speech_readers_manifest.csv` 与 `speech_near_eval.txt` / `speech_far_eval.txt` 逐集合核对：

```
train70 = 223 readers, val15 = 37, holdout15 = 45
train70 ∩ holdout15 = 0
val15   ∩ holdout15 = 0
train70 ∩ eval(near ∪ far) = 0
eval near ∩ eval far = 0
non-eval(train70 ∪ val15) ∩ holdout15 = 0     <-- 替代方案的关键硬约束，成立
```

- 替代用的 260 个 non-eval readers **与 eval_v8 的 45 个 holdout readers 零交集**，因此
  "far 端替代"不会与评测读着重叠。
- 注意：`train70` 同时充当 near 与 far 训练池时，**同一 reader 可能出现在两端**——这是
  `REMEDIATION_PLAN_V3.1.md` §3.1 的既定口径（near 70% / far 70% 互斥是按 reader 选取、
  允许共享），且 `aec_synth.py --nearfar-mutex utterance` 会拦住**同一条 utterance** 的双端复用。
  更严格的 reader 级互斥（near/far 完全不共享 reader）已按队长裁决执行：见第 6 节
  （`speech_near_train70.txt` / `speech_far_train70.txt`）。
- 说明：队长口径写的"76 个非评测 reader"与仓内清单不符——仓内 `speech_readers_*.txt` 可导出的是
  **223 + 37 = 260** 个 non-eval readers；已按 260 执行并核对通过（见上）。

## 6. train70 reader 级 near/far 再切（2026-10-13 队长裁决）

- 背景：评测轴已做到 reader 级互斥（`eval near ∩ eval far = 0`），训练分布应与评测一致；
  方案 §3.1 原文即"far 池 70%（与 near 互斥）"。
- 做法：`train70` 的 223 readers 按 `sha256('nearfar_train:'+reader)[:8]` 升序排序，
  前 111 个 → `speech_near_train70.txt`（near 训练池），余 112 → `speech_far_train70.txt`（far 训练池）。
- 实测核对（全 0 / 全真）：
  ```
  near ∩ far = 0 ; near ∩ holdout15 = 0 ; far ∩ holdout15 = 0 ; (near ∪ far) == train70
  hash 唯一性：223/223（无碰撞）
  ```
- 计数：near_train 111 readers / 3477 文件；far_train 112 readers / 3675 文件。
  元数据与两文件 sha256 见 `speech_nearfar_train_meta.json`。
- **代价（如实记录）**：训练池每端**减半**（每端 reader 从 223 → ~111，文件 ~7152 → ~3500），
  组合多样性下降；换来 reader 级 near/far 互斥与评测轴一致。utterance 级
  `--nearfar-mutex utterance` 照开（双保险）。
- 影响：t10/t12 训练命令的 near/far 池改用这两个清单；t11 若涉及 near/far 口径同步。

## 7. 入库记录：LibriSpeech tc100 + MUSAN（2026-10-13，ModelScope 快路）

### 7.1 为什么改判
原结论"双端到 openslr 仅 22–35 KB/s（83h/128h）"成立，但**源**选错了。改测
**ModelScope（modelscope.cn，阿里系国内 CDN）**后：

| 目标 | 仓库/文件 | 实测速率 | 实际耗时 |
|---|---|---|---|
| LibriSpeech train-clean-100 | `pkufool/LibriSpeech` → `train-clean-100.tar.gz`（6,387,309,499 B） | **持续 60s 实测 15.25 MB/s**（非突刺） | 下载 ~9 分钟（与 MUSAN 并发） |
| MUSAN 全量 | `manyeyes/MUSAN` → `raw/musan.tar.gz`（11,086,114,085 B） | **18.45 MB/s**（采样） | 下载 ~22 分钟（与 LS 并发） |

- 对比 openslr 直连 22–35 KB/s → **~450×**。本机侧同样可达 14.28 MB/s（双路冗余）。
- 可用 URL 形态：`https://modelscope.cn/datasets/<org>/<name>/resolve/master/<path>`；
  列目录 API 是 `/api/v1/datasets/<repo>/repo/tree?Revision=master&Root=<dir>`
  （**不是** HF 的 `/tree`、也**不是** `/oss/tree`——那两个在 ModelScope 返回空数组）。
- `oss.openslr.org`（队长要求复查的 aliyun OSS 路径）：http/https **均无响应**，确认不可用，
  早先 "aliyun 404" 的结论维持——但已不重要，ModelScope 更快。

### 7.2 落地与校验（服务器 `/root/data`）
| 数据集 | 压缩包大小 | 校验 | 解压后 | 文件数 | 留痕 |
|---|---|---|---|---|---|
| LibriSpeech train-clean-100 | 6,387,309,499 B（**与仓库声明逐字节相同**） | `gzip -t` 通过；压缩包 sha256 `d4ddd1d5a6ab…` | `/root/data/librispeech/LibriSpeech/train-clean-100/` | 29,129（其中 train-clean-100 内 **28,539 flac**；含 `SPEAKERS.TXT` 等） | `provenance/20261013/librispeech.json` |
| MUSAN | 11,086,114,085 B（**精确匹配**） | `gzip -t` 通过；压缩包 sha256 `86d1061c7e15…` | `/root/data/musan/musan/{music,noise,speech}/` | 2,037（music 4.6G / noise 687M / speech） | `provenance/20261013/musan.json` |

- 磁盘纪律：**解压后立即删压缩包**（两个 tarball 已删）；全程峰值占用 ~41GB/128G。

  `/root/avsuite/manifests/provenance/20261013/`。

### 8.4 扩展池切分（`ext_*`，与既有冻结轴零交集）

- 规则与 0-2/0-4 同族：说话人语料 `sha256('<corpus>:reader:'+speaker)[:8] % 1000` → <700 train70 /
  700-849 val15 / ≥850 holdout15；holdout 内再按 `sha256('<corpus>:nearfar:'+speaker)[:8] % 1000`
  → <500 near_eval / ≥500 far_eval。MUSAN 无说话人概念，按**相对路径**
  `sha256('musan:file:'+rel)[:8] % 1000` 同样三分。
- **硬互斥**：与全部冻结评测轴零交集 —— `speech_readers_holdout15.txt`(45)、
  `speech_near_eval/far_eval` 出现的 reader(45)、`noise_eval15.txt`(95，MUSAN 按 basename 比对)、
  `rir_holdout15.txt`(8，登记比对)。
- 实测产出：LibriSpeech **798/176/198**（评测 near 11,786 / far 10,606）、
  AISHELL-3 **130/22/22**（4,612 / 3,229）、MUSAN **1,420/293/303**。
- 生成/验收：`scripts/split_extension_pools.py` / `scripts/verify_extension_pools.py`
  （meta 记计数+sha256、空份额拒绝落盘、验收 exit 0/1/2、与冻结轴零交集断言）。
- **不改动任何冻结清单**：`ext_*` 全为新文件；既有 `speech_*`/`noise_*`/`rir_*` 只读。
- 参数组合（near/far/噪声/DT/mutex/权重起点）：见同目录
  [`EXT_POOL_TRAINING_PARAMS.md`](EXT_POOL_TRAINING_PARAMS.md)。
