## 动因（复评四大发现）

1. **两个"证伪"headline 的实验设计偏置**：
   - 漂移："线性 AEC 系统性崩塌"实为零余量一次性对齐（`pipeline.py:82-85` 全链唯一 GCC、
     `align_far` 把直达径放在滤波器 lag 0）+ DTD 误冻正反馈（闩锁只置位不复位）所致——
     负向漂移非因果、任何 FIR 不可表示；同时 NN 的"结构性稳健"与"jitter 分布覆盖"
     未被判别实验区分；
   - Kalman："Kalman 优于 MDF 被推翻"测的是固定 q/r 外壳（R 挂 far 功率、Q 绝对单位、
     复用 MDT 冻结且冻结连带冻协方差演化），FKF 三件本质件未装，结论被上层报告过度普化。
2. **级联（生产推荐形态）零真实数据验证**：官方集/OOD/真实 RIR/漂移/说话人 held-out
   全部只有传统与全 NN 两列。
3. **文档双层真相**：权威层（NUMBERS+3.5 波报告）与面试层（STORY/CHEATSHEET/INTERVIEW/
   README）断裂——80 vs 93、"生产回级联"话术、AECMOS"三分量"事实错误、ADR 0005 未随
   eval_v5 推翻结论更新、NUMBERS 内部自相矛盾（"级联价值在 deg 保底"）与 20.55/20.37
   口径混淆。
4. **治理缺口**：3.5 波全部产物未提交 git；ADR 0006 承诺未交付；P2-3（多麦）无声消失；
   第三波评估脚本（official_aecmos_eval/compute_ci/precompute_cascade/kalman）零测试。
