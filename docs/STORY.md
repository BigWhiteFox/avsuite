## S — 场景（20 秒）

车厢免提通话有两个最脏的问题：**回声**（对端声音经扬声器→车厢反射→又被麦克风收回去，
对方听到自己的声音）和**噪声**（胎噪/风噪/空调）。车载音频岗的核心就是把近端说话人
的声音干净地送出去。我做了**一套从信号处理地基到神经网络、再到端侧部署的完整方案**。

## T — 任务（10 秒）

目标：用 12 周把"传统 AEC → 神经网络增强 → 端侧 INT8 部署"这条链**全部亲手实现并测通**，
不调包、每个指标都能复现、每个设计决策都能讲清为什么。

## A — 行动（40 秒，讲 3 个最硬的点）

1. **传统 AEC 从白纸写起**（纯 numpy，零 GPU）：GCC-PHAT 时延估计 + MDF 频域自适应 +
   双讲检测状态机。双讲检测我没抄教科书——时域相关在随机 RIR 下误报，我改成 WebRTC 同款的
   mic-vs-回声估计相干，叠加收敛闩锁和远端静默冻结，**每一条规则都对应一个实测踩过的坑**。

2. **神经网络回声消除（0.638M 因果模型）**：far 参考 + mic 复数谱进压缩 CRN，时间维严格
   因果——**因果性不是声称的，是单测锁死的**（扰动未来输入，过去输出逐位不变）。我做了一个
   干净的对照实验：全 NN vs 传统在同一评估集，发现 **NN 在双讲段回声抑制完胜（echo_mos
   3.75 vs 2.47），但近端保真输给传统**——所以我得出的生产结论是级联，这也正是工业界主流。

3. **端侧部署全链路**：GTCRN（23.67K 参数）移植 → ONNX 导出对拍 6e-6 → INT8 量化。
   最有价值的是一个**负面结果**：静态 INT8 直接崩坏，我定位到是 GRU 状态量化误差逐帧累积 +
   小模型无冗余，给出 QAT/混合精度的量产路径。

## R — 结果（20 秒，报 3 个数 + 1 个诚实）

- 回声抑制：双讲 echo_mos **3.75 vs 传统 2.47**（AECMOS 官方口径，双倍达标）
- 降噪：VoiceBank PESQ **1.97 → 2.53**（824 对测试集）
- 端侧：CPU RTF **0.0084**（实时性 120 倍余量）、**80 项单测全绿**
- 诚实一条：NN-AEC 近端保真（deg_mos 1.74）目前不如传统（2.40），我用五变体实验证明
  这是**模型形态与评估定义的结构性瓶颈，不是欠训**——所以生产方案我推荐级联。
