# INTERVIEW — WP-02 损失函数（模块2）

## 3 分钟讲解提纲

**第 1 分钟：时域 SI-SNR —— 为什么是分离任务的默认起点**
- 三步：零均值化（DC 偏置不属于干扰）→ 向参考投影消尺度（设备增益不可知，scale-invariant 公平评估）→ 投影能量/残差能量 取 10log10
- 尺度不变性同时防止模型走捷径学全局增益

**第 2 分钟：谱域损失 —— 掩码模型与复数模型各配各的**
- 复数谱 MSE：Re/Im 两路等权，相位隐含学习（配 DCCRN 系）
- IRM + BCE：目标是 (0,1) 的幅度增益，BCE 梯度形态陡、天然匹配 sigmoid 输出（配 CRN 系）；IRM = sqrt(Ps/(Ps+Pn))，开方对应幅度域 Wiener 增益
- 纯谱 MSE 的坑：不同频带能量差 2-3 个量级，损失被高能量 bin 主导 → 引出加权

**第 3 分钟：感知加权与多尺度 —— 把"人耳怎么听"写进损失**
- power-law 加权：w = |S|^γ（γ≈0.5，Stevens 幂律响度 ∝ 幅度^0.6），响的地方错一点罚更重；γ=0 严格退化为普通复数 MSE（我单测里校验）
- 多尺度 STFT loss：单窗受时频不确定性约束，短窗管瞬态、长窗管谐波包络，(512,1024,2048) 三尺度求和（HiFi-GAN 式：谱收敛 + log 幅度）

## 高频追问预案

**Q1 SI-SNR 为什么先零均值？**
直流/偏置是采集链路问题，不是干扰能量；不除掉它 est=ref+c 会被全算成噪声。SI-SNR 的"invariant"有两个：均值（减掉）和尺度（投影掉）。

**Q2 SI-SNR 和 SI-SDR 是什么关系？**
同一指标的两种叫法（SDR=distortion reduction ratio 文献混用），实现差异只在 eps 约定。知道这个能显得读过原始文献（Le Roux et al., 2019 提出统一形式）。

**Q3 PIT 是什么？什么时候需要？**
Permutation Invariant Training：多说话人分离时输出与参考的配对不固定，训练时穷举排列取最小损失。单通道单目标增强不需要；TSE/多说话人（WP-11）需要。

**Q4 IRM 为什么开方？cIRM 是什么？**
IRM 原始定义是幅度域掩码：|S|/|X| 的最优 L1 近似 ≈ sqrt(Ps/(Ps+Pn))（功率比的平方根 = 幅度比估计）。它乘在带噪复谱上只改幅度、动不了相位。cIRM（复数理想比率掩码）是复数域的 Wiener 解 X/S，能同时修正相位，但目标是复数、需要特殊训练策略。

**Q5 掩码用 BCE 还是 MSE？**
目标在 (0,1)、模型输出 sigmoid → BCE 梯度在错误置信处更陡（−1/x 形态），收敛快；MSE 会饱和。也有工作用 L1 on mask（对离群掩码值更稳）。我的库实现了 BCE 版，消融时留了接口。

**Q6 加权失真的 γ 有感知依据吗？**
Stevens 幂律：主观响度 ∝ 声强的 0.3 次幂 ≈ 幅度的 0.6 次幂。用 |S|^0.5-0.6 加权谱误差，等价于把"等响度误差"作为优化目标；γ=0 退化为复数 MSE，γ→1 退化为幅度域加权。AEC 文献（Ivry 系列）常用这类加权失真做近端语音保真。

**Q7 多尺度 STFT loss 为什么比单尺度好？给个直觉。**
32ms 窗看得清谐波但把 5ms 瞬态糊掉；8ms 窗反之。增强后的"闷/糊"感往往来自长窗谐音结构损失、"沙沙"伪影来自短窗噪声残留——多尺度同时罚两种失真。代价：计算 ×3，推理不用（只训练用）。

**Q8 loss 发散/NaN 先查什么？**
清单：① 时域损失有没有零均值化 + eps clamp；② 掩码有没有 clamp(eps, 1−eps) 再 log/BCE；③ 谱损失输入是不是复数（实数张量调 .real 会报错）；④ lr 与梯度裁剪；⑤ 数据里有没有全静音段（PESQ 也一样会 NaN）。

## 必默写公式
- SI-SNR：`10·log10( ||s_target||² / ||e_noise||² )`，`s_target = <ŝ,s>/||s||²·s`
- IRM：`sqrt( Ps / (Ps + Pn) )`，`Pn = max(Pmix − Ps, ε)`
- 多尺度：`Σ_i [ |||E|−|R|||_F / (|||R|||_F+|||E|||_F) + mean|log|E|−log|R|| ]`
