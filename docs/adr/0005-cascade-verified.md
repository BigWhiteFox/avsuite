# ADR 0005 — 级联 AEC 实测验证:「级联 = 同一个 0.638M 双输入模型换一对输入」

- 状态:已确认(实测完成;级联 DoD:echo 达标 / deg 未达标)
- 日期:2026-10-11
- 关联:`exp/09_cascade_aec/`、`exp/07_nn_aec/`、`exp/09_cascade_aec/results/THREE_WAY.md`、
  `exp/09_cascade_aec/results/ZEROTRAIN.md`(并行任务)、`reports/rectification/exec/P1-1.md`、
  [ADR 0002](0002-fullnn-vs-cascade-aec.md)

## 背景

[ADR 0002](0002-fullnn-vs-cascade-aec.md) 实测:全 NN v4 在双讲回声抑制上完胜传统(DT echo 3.754 vs
2.467),但近端保真结构性落败(DT deg 1.743 vs 2.401),并给出 fallback:"级联能两者兼得"——线性级
保底近端保真、NN 只消非线性残余(微软 AEC-Challenge 冠军主流)。本 ADR 把这条 fallback 做成实测,
顺带验证一个更强的工程判断:**级联不需要新模型,只是换一对输入**。

## 决策:级联 = 换输入对(不新增模型、不改训练代码)

同一个 0.638M 双输入 NNAEC(v4 架构/损失/管道一字不改,`train.py`/`dataset.py`/`model.py` 只读复用),
把喂进去的数据换掉:

```
全 NN : mic 槽 = 原始 mic          far 槽 = 原始 farend(未对齐,39–70ms 随机时延)
级联  : mic 槽 = e_lin = mic − y_echo(MDF 线性残差)   far 槽 = y_echo(已 GCC-PHAT 对齐的回声估计)
```

- y_echo 由 `TradAEC(MDF, partitions=8, mu=0.7)` 逐条预计算(`precompute_cascade.py`,3000 条全量
  283s;与 WP-06 评估、WP-08 precompute_lin 完全同参)——线性级消化 10–80ms 时延 + 100ms RIR 的
  长记忆,NN 在已对齐的 (残差, 回声估计) 对上学 memoryless 的非线性残余(Ivry 2021 / 冠军结构);
- nearend 目标、manifest、场景标签不变;训练超参照 v4 ckpt 内嵌 cfg(gamma 0.5 / w_sisnr 1.0 /
  scenarios dt,nst / jitter 10ms / batch 16 / seed 0),任务口径 epochs 40 / early-stop 8。
- 另有零训练下界(并行任务):v4 权重**原封不动**直接吃 (e_lin, y_echo)——见 `results/ZEROTRAIN.md`。

## 实测数字(eval_v3 60 条,AECMOS 同集同口径;完整表与重跑命令见 results/THREE_WAY.md)

| 场景 | 指标 | 传统 WP-06 | 全 NN v4 | 零训练级联 | **级联 P1-1(40ep)** | 级联收敛(64ep 早停) |
|---|---|---|---|---|---|---|
| **DT** | echo_mos | 2.467 | 3.754 | 3.174 | **3.919** | 3.898 |
| **DT** | deg_mos | **2.401** | 1.743 | 1.887 | 1.785 | 1.846 |
| FEST | echo_mos | 3.836 | 3.762 | 3.003 | **4.502** | 4.340 |
| NST | deg_mos | **2.665** | 2.073 | 2.013 | 2.081 | 2.190 |
| OVRL | echo_mos | 3.904 | 4.173 | 3.708 | **4.532** | — |

级联 DoD(echo≥3.5 且 deg≥2.2,DT 口径):**echo ✅(3.919,三方最高),deg ❌(1.785)——未达成**。
训练止损注记:40ep 全程跑完(04:00 硬止损未启用),best@epoch 39;补充的 250ep 收敛口径在
epoch 64 早停(best@39,val 23.57 vs 40ep 24.00),DT deg 仅 1.785→1.846——**欠训假设被排除,
deg 是结构性的**。

## 核心结论

1. **「级联=换输入对」在回声维度完全成立**:不训练(零训练级联)现成 v4 权重就拿到 DT echo 3.174
   (传统 2.467 的 +0.707),级联训练再 +0.745 至 3.919 三方最高;FEST echo 4.502 也是三方最高
   (零训练时 3.003 的分布偏移问题被训练修复)。全链路推理(每条先 MDF 再 NN)60 条仅 11s。
2. **近端保真病理不在级联接口**:DT deg 在全 NN 1.743 / 零训练级联 1.887 / 训练级联 1.785(收敛
   1.846)之间不动,距传统 2.401 恒差 ~0.6。逐条看是普遍 1.5–1.9 的过度抑制、无单条崩塌;传统的
   deg 来自 DTD 冻结(近端帧直通),掩码 NN 没有等价机制。**deg 的下一步在掩码(近端门控/直通偏置/
   损失加权),不在接口**——本 WP 不展开。
3. **收益可分离**:零训练→训练,DT echo +0.745、FEST echo +1.499,DT deg −0.102——回声抑制收益
   来自级联训练,近端病理来自结构;两件事独立。

## 后果

- 正面:三方对照矩阵补齐第三列且每列可复现(THREE_WAY.md);AECMOS OVRL echo 4.532 全场最高;
  级联的边际工程成本极低——预计算 4.7 min + 训练 4.5 min(40ep)+ 推理 11s,模型/代码零改动。
- 负面/未解:DT/NST deg 未回传统水平,DoD 半达成;若产品红线是近端保真,级联 NN 级需加近端门控
  (trad 的 DTD 思路)或掩码直通偏置,否则宁可用传统。
- 训练数据侧注:级联输入对以 FLOAT 子类型落盘(实测 4/40 条 y_echo 峰值>1.0、max 1.78,PCM_16
  会削波且与推理期 float32 不一致);推理端 MDF 与预计算目录逐位一致(max|Δ|=0,MDF 确定性)。

## 面试标准答案

> "我把 ADR 0002 的 fallback 做成了实测:级联不用新模型——同一个 0.638M 双输入网络,把输入从
> (原始 mic, 原始 far) 换成 (MDF 线性残差, 已对齐的回声估计) 就是级联。实测两件事:一是回声抑制
> 全面丰收——零训练换输入对 DT echo 就从 2.467 到 3.174,训练后 3.919 三方最高,FEST 也最高,
> 因为线性级消化了 180ms 回声记忆、网络只学 memoryless 残余;二是近端保真没救回来——deg 三条路
> (全 NN/零训练级联/训练级联)全落 1.7~1.9,传统 2.401 靠的是 DTD 冻结,掩码网络没有这个机制,
> 我用 250ep 收敛口径排除了欠训。所以结论是:级联接口解决'学不学得动',掩码结构决定'擦多少'——
> 下一步是给 NN 级加近端门控,而不是继续调接口。"

## 后续

- NN 级加近端门控/直通偏置(对着 DT deg 2.2 打);掩码直通偏置(m = 1 − Δ)是最小改动;
- 级联输入对下重审 γ / w_sisnr 配比(deg 导向的消融,本 WP 未动);
- 车载实测 RIR 上的级联鲁棒性(时延漂移由 MDF 跟踪,NN 输入对天然抗漂移,值得验证)。
