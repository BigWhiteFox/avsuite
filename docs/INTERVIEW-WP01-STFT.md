# INTERVIEW — WP-01 STFT/ISTFT/流式（模块1）

## 3 分钟讲解提纲

**第 1 分钟：为什么要到时频域**
- 语音是非平稳信号：短时（20-40ms）内近似平稳 → 加窗分帧，每帧做 FFT
- 噪声与语音在时频域可分性远好于时域：语音能量集中在谐波/共振峰，噪声常宽带平稳
- 于是增强 = 逐 T-F 单元的估计问题（掩码 / 谱映射），催生 CRN/DCCRN 全家族

**第 2 分钟：STFT-ISTFT 的机械结构**
- `X(t,f) = Σ x[n+t·hop]·w[n]·e^{-j2πkn/N}`；窗（hann）压旁瓣，hop=50% 重叠
- 重构两条路：COLA（窗和恒定，免归一化）与 WOLA（除以窗平方和，任意窗精确）——torch.istft 是后者，我们自实现的也是，对拍 <1e-10
- 我自己实现过一版并与 torch.stft 对拍：关键是 center padding（两侧各 N/2）与周期窗约定，差一点数值就差 1e-6 以上

**第 3 分钟：流式与工程参数**
- 车载 20ms 帧移 @16k = 320 样本；常用 n_fft=512/32ms 窗、hop=256——2 的幂利于 FFT，50% 重叠满足 hann COLA
- 流式实现：cache 只留 n_fft−1 个历史样本（有界），帧右端到齐即输出；算法时延 = 窗长 32ms，其中 lookahead = 窗长−帧移 = 16ms
- 端到端时延账本要算上：算法 lookahead + 模型感受野 + 设备缓冲

## 高频追问预案

**Q1 为什么用复数谱（Re/Im）而不只用幅度谱？**
幅度谱丢了相位，ISTFT 只能借用带噪相位；相位携带瞬态/结构信息，纯幅度重建听感发闷、类似声码器伪影。复数谱 Re/Im 是"把相位隐含地学进来"的最直接方式（DCCRN 的路线）。

**Q2 相位为什么不能直接用 MSE 回归？（必考）**
三点：① ±π 卷绕不连续——3.14 与 −3.14 物理上几乎相同，MSE 却差 (2π)²，梯度被边界跳变主导；② 相位差 2π 等价、目标不唯一，回归是病态问题；③ unwrapping 依赖平滑性，噪声下不可靠。替代：Re/Im 回归、幅度掩码+带噪相位、或相位感知损失。

**Q3 窗长怎么选？权衡是什么？**
不确定性原理：Δf·Δt ≥ 常数。窗长 32ms → 主瓣 -6dB 宽 ≈ 31Hz（我实测），男声基频 100-150Hz 的谐波间隔勉强可分；窗加长频率准但瞬态拖尾变长（实测起振拖尾 ≈ 窗长），窗短反之。语音常用 20-40ms；车载追求低时延常取 20ms 帧 + 32ms 窗。

**Q4 COLA 条件是重构的必要条件吗？**
不是。COLA 是"免归一化直接 overlap-add"的充分条件。ISTFT 除以窗平方和（WOLA）后，任意窗 + hop≤n_fft 都精确重构——我实测 blackman@50% COLA 偏差 0.38，往返误差仍 1e-15。这句话能把问题从"背条件"拉到"懂机制"。

**Q5 流式推理和离线有什么差别？**
① 左 padding：离线可 reflect（用未来样本），流式只能零填充——最左帧边缘样本有差异；② 输出节拍：帧右端样本到齐才能产出，自然形成 lookahead；③ cache 管理：卷积 cache + RNN state（WP-05b 深入），STFT 级 cache 是 n_fft−1 样本，有界；④ 尾帧用零 flush 结算。我的实现里流式与离线逐帧对拍 <1e-10。

**Q6 center padding 有什么用？**
两侧各 N/2 后，第 t 帧的中心对齐时间轴的 t·hop 位置：时间戳语义干净（帧 t ↔ 中心时刻 t·hop/sr）、边界样本也能被完整覆盖。代价是引入 N/2 的 pad 区，流式时要靠零注入等价实现。

**Q7 为什么 16k 采样率下常用 512 点 FFT？**
32ms 窗覆盖音素级平稳段；F=257 维、2 的幂 FFT 高效；50% 重叠 hann 满足 COLA/WOLA 归一化平稳。若 20ms 帧（320 样本）做帧长，FFT 常补零到 512 保频谱分辨率与算子复用。

**Q8 float32 误差多少？为什么？**
对拍 torch.stft float32 相对误差 ~1e-6（FFT 累加舍入），float64 <1e-10。窗系数我以 float64 生成再 cast——先 f32 再升 f64 的窗会带进 1e-8 级偏差，这是我自己实现时踩过的坑。

**Q9 STFT 能用卷积等价实现吗？**
能：分析 = 与窗卷积后抽稀（stride=hop）+ 矩阵 FFT；综合 = 转置卷积。流式推理时用"分块矩阵乘"等价实现可省 unfold 拷贝（WP-05b 的 C++ 单帧推理会用到该视角）。

## 必默写公式
- STFT：`X[t,k] = Σ_n x[t·hop+n]·w[n]·e^{−j2πkn/N}`
- WOLA：`y[n] = Σ_t w[n−t·hop]·frame_t[n−t·hop] / Σ_t w²[n−t·hop]`
- COLA：`Σ_t w[n−t·hop] = C`
