## 结构速记（白板可画）
- **增强**：STFT(512/320) → CRN(3enc+BLSTM+3dec) → cRM⊙带噪谱 → ISTFT
- **NN-AEC**：mic+far 复谱(4ch) → 3×因果复数卷积(257→33) → 单向LSTM(96) → 因果反卷积 → cRM
- **传统 AEC**：GCC-PHAT → MDF → DTD 三态(自适应/软冻/硬冻) → RES
- **部署**：GTCRN(ERB 129 维) → ONNX → INT8；流式=conv cache+LSTM state
