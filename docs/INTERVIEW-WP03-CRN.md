# INTERVIEW — WP-03 CRN（模块3）

## 3 分钟讲解提纲

**第 1 分钟：从掩码思想到 CRN 架构**
- 谱减告诉我们：T-F 域逐单元处理可行，但手工规则（减多少、地板多少）到头了
- 掩码范式：enh = M ⊙ noisy——IRM 幅度掩码 / cRM 复数掩码（能修相位）
- CRN = "怎么估计 M"：CNN 看局部谱纹理，RNN 沿时间聚合，合成端对称还原

**第 2 分钟：具体结构（对着图讲）**
- 编码 3×Conv(k5, s(2,1))：频率 257→33 压缩、时间不动——**时间分辨率是流式的命根子**
- 2×BLSTM(256)：把 40ch×33bin flatten 成 1320 维序列（帧序列）
- 对称解码 DeConv×3 + 跳连 concat：恢复频率分辨率，细节不丢
- 输出 cRM（Re/Im 两通道）乘回带噪复谱 → ISTFT。损失：复数谱 MSE（IRM 变体配 BCE）

**第 3 分钟：训练协议与验证**
- VoiceBank-DEMAND 11572 对；3s 随机裁剪、说话人不相交 val（p226 前缀分组防泄漏）
- Adam 1e-3 + ReduceLROnPlateau + early stop + 断点续训；5.6M 参数，4060 上 3.3min/epoch
- 单 batch 过拟合 sanity（loss 降 40%+）→ 全量训练 → 测试集 PESQ/STOI/SI-SNR（eval.py 全长推理）

## 高频追问预案

**Q1 CRN 相比谱减/传统方法强在哪？**
三层：①非线性映射能力——掩码是数据驱动学的，不是假设噪声平稳；②复数掩码能修相位，谱减只能保带噪相位；③序列建模（RNN）利用语音的时间结构。代价：需要成对数据、计算量。

**Q2 为什么用 LSTM 而不是 GRU/Attention/Conformer？**
历史脉络：CRN(2018)→CRNN 变体→DCCRN(复数化)→DTLN/GTCRN(轻量化)→Conformer(2021后)。LSTM 参数效率和长时依赖平衡好、流式 cache 天然（一个 state 向量）；GRU 少 1/4 参数但记忆容量略低；自注意力要 locality 约束才能流式。我实现里留了 blstm/lstm 开关做消融——blstm 非因果（双向），单讲增强离线可接受，实时链路必须换单向。

**Q3 cRM 为什么有界化（tanh）？什么时候不界？**
cRM 理论值是复数 Wiener 增益 X/S，模长可以远大于 1（低信噪比 bin 要大幅放大）。有界化（如 1.55·tanh，Lennox et al.）稳定训练但压低放大能力；无界线性输出上限高但早期不稳。我两个都实现了（--bounded-mask），消融决定。

**Q4 频率维降采样、时间维不降，为什么？**
频率维有 257 bin 高度冗余（相邻 bin 强相关），压到 33 让 RNN 输入从 257×ch 降到 33×ch，参数量骤减；时间维 stride=1 保留每帧输出——流式 20ms 一帧的处理要求逐帧出掩码，一旦时间下采样就得等未来帧，引入额外时延。

**Q5 跳连（skip connection）的作用？**
U-Net 式：编码层的高分辨率特征直通解码层，避免 33bin 瓶颈丢细节；对消融 noskip 的差异就是"频率细节恢复能力"。实测参数量 skip 略多（concat 翻倍解码输入通道），值回票价。

**Q6 训练用 3s 片段，推理全长——不一致没问题吗？**
RNN 是状态滚动的，长度泛化天然 OK；不一致的是 BN（如果有的话——本模型用 ReLU 无 BN，规避了）。评估必须全长/batch=1：padding 会在 T 维产生"假帧"，污染边界。

**Q7 数据泄漏怎么防？**
说话人不相交切分（train/val 按说话人前缀分组）；VoiceBank 官方 test 本身说话人不与 train 重叠。切分代码在 `dataset.speaker_split`，单测验证交集为空。

**Q8 怎么判断训练有没有"学废"？**
梯度检查（有限性）→ 单 batch 过拟合（loss 应降到 <60% 初值，我的单测断言这个）→ val 曲线与 train 同步降 → 测试集指标 vs 带噪基线。任何一步异常都是结构/损失/数据 bug，不是"再多训会儿"能救的。

**Q9 如果 PESQ 只到 2.2（差 0.1 达标）你先查什么？**
①训练时长/early stop 是否过早；②lr 调度（Plateau patience）；③掩码类型换 cRM/有界开关；④混合 SI-SNR 损失（--si-snr-weight 0.2，常见 +0.05~0.1 PESQ）；⑤DM 数据增广（WP-04 的手段前移）。这也是我们 WORKLIST 的降级路径：差距分析本身值钱。

## 必默写公式
- cRM：`M = S / X`（复数除法）；有界版 `M = 1.55·tanh(θ)`
- 编码尺寸：`F' = (F−1)//2 + 1`（k5,p2,s2）——我踩过 (F+4)//2 的坑，会背
