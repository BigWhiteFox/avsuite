**统一决策（2026-10-10 定版）**：
- NN-AEC **主配置 = v4**（γ0.5 / w_sisnr 1.0 / DT-NST 专注 / 240ep），对外只报 v4；v3 等作为探索矩阵存档。
- DCCRN **主结果 = 2.1811**（devtest 150 条口径），统一弃用旧值 2.161（后者是早期 synth100 口径）。
- NN-AEC 近端保真的口径结论（2026-10-11 口径修复后收窄）= **"DT 段存在 AECMOS-deg 落后（−0.36~−0.37，CI 不含 0），机理为高频带选择性损伤 + 谱平坦化"**；~~"模型形态与 AECMOS-deg 定义之间的（全场景）结构性瓶颈"~~ **该表述作废**——AECMOS@48k 口径修复后 NST/近端退化维度上 NN 不再落后（NST deg 7/7 集由显著落后转为不显著或略优）；"禁用欠训表述"纪律继续有效。

**统一决策（2026-10-11 增补，数据充分性整改）**：
- GTCRN 量化/对拍参照口径 = **held-out 200 条**（旧 50 条点估计全部落在新 CI 内；INT8 static 崩坏数字仍为旧 50 条口径，未重评）。
- AEC 三方对照的稳健口径 = **eval_v5 DT 154 条**（eval_v3 降为历史对照；"级联 echo 优于纯 NN"的旧表述作废，Δ+0.02 属噪声级）。
- 全仓 DCCRN real-conv 表述统一为"与复数性能相当（Δ0.009 噪声级），复数赢在参数效率"，不称"反超"（ADR 0004）。
- 所有 DT 场景 AECMOS 对外引用须带 95%CI（工具 `tools/compute_ci.py`，汇总 `reports/DATA_CI.md`）。
- **AECMOS 口径统一为「@48k 模型协议」（2026-10-11 口径修复）**：`AECMOS_local/aecmos.py` 对 `Run_1668423760_Stage_0.onnx` 设 `sampling_rate=48000`，官方入口用 `librosa.load(sr=48000)`；本仓 `aecmos_eval.py` 曾以 16k 波形直送（绕过重采样）⇒ **全部自合成集分数失真**。现已送评前统一重采样到模型采样率（`resample_poly`，gcd 约简）。**旧值全部作废**（各节保留一行历史脚注）；官方 48k 链（official_aecmos / ood_real_echoes / 官方 800 段表）本就正确、未受影响。影响面、逐集对照与新 CI 见 `reports/aecmos_rescore_v5fix.md`。

**统一决策（2026-10-11 V4 整改第四波增补）**：
- 传统 AEC 漂移崩塌主导机制改判 = **块内路径移动 × 块级自适应的跟踪代价**（"零余量对齐→非因果泄漏"被 S10 消融证伪；官方集发散条这一真·实现缺陷已由 S1 发散防护治愈）。
- 级联 MDF→NN 的真实数据定位（S11）：echo 增益≈NN 且显著优于传统（官方集 + eval_v6）；deg 交易结构照旧；**级联拒评 2/800 须随"生产推荐"话术一并披露**。
- NN deg 差的机理（S5）= **高频带选择性损伤 + 谱平坦化**（非宽带能量压低、非单纯过度抑制）。

### NN deg 机理直接量化（V4-S5，2026-10-11；"过度抑制 vs 伪影"一锤定音）
| 项 | 测量结论 |
|---|---|
| DT 近端短板机制 | **高频带选择性损伤**（4–8 kHz 频带 NLA 中位 **−2.41 dB**）+ **谱平坦化**，**非宽带能量压低** |
| 传统 deg 优势来源 | 冻结/透传 NLA（**+0.07 dB**，≈无损）——传统列"不动近端"是机制性的 |
| 自检 | 重建 6/6 逐位 PASS、复算 15/15 PASS |

> <sub>回答复评"NN 的 deg 差是过度抑制还是伪影"：两者都不是宽带压低——是高频带选择性损伤 + 谱平坦化（伪影类）；
> 传统列的 deg 优势来自冻结透传 NLA 近乎无损，非"抑制更强"。三方（NLA/lead-in 回声抑制/分频带）主表与 5 条手工抽查见
> `reports/deg_mechanism.md`；驱动 `exp/07_nn_aec/deg_mechanism.py`；数据 `exp/07_nn_aec/outputs/deg_mechanism/`。</sub>

> <sub>**口径注（2026-10-11，随 AECMOS@48k 修复补）**：本节 NLA 中位 −2.41 dB、冻结透传 +0.07 dB 等
