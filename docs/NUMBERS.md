> 本文件是全仓所有对外数字的**唯一权威来源**。README / ACCEPTANCE / INTERVIEW / 简历 /
> 面试口述中的任何指标，都必须与本表一致；如不一致，以本表为准并回改对应文档。
> 更新纪律：任何新训练/评估完成后，先改本表（注明 checkpoint + 数据口径 + 日期），再同步其它文档。

**统一决策（2026-10-10 定版）**：
- NN-AEC **主配置 = v4**（γ0.5 / w_sisnr 1.0 / DT-NST 专注 / 240ep），对外只报 v4；v3 等作为探索矩阵存档。
- DCCRN **主结果 = 2.1811**（devtest 150 条口径），统一弃用旧值 2.161（后者是早期 synth100 口径）。
- NN-AEC 近端保真的官方结论 = **"模型形态与 AECMOS-deg 定义之间的结构性瓶颈"**（非"欠训"），禁用"仍欠训"表述。

**统一决策（2026-10-11 增补，数据充分性整改）**：
- GTCRN 量化/对拍参照口径 = **held-out 200 条**（旧 50 条点估计全部落在新 CI 内；INT8 static 崩坏数字仍为旧 50 条口径，未重评）。
- AEC 三方对照的稳健口径 = **eval_v5 DT 154 条**（eval_v3 降为历史对照；"级联 echo 优于纯 NN"的旧表述作废，Δ+0.02 属噪声级）。
- 全仓 DCCRN real-conv 表述统一为"与复数性能相当（Δ0.009 噪声级），复数赢在参数效率"，不称"反超"（ADR 0004）。
- 所有 DT 场景 AECMOS 对外引用须带 95%CI（工具 `tools/compute_ci.py`，汇总 `reports/DATA_CI.md`）。

**统一决策（2026-10-11 V4 整改第四波增补）**：
- 传统 AEC 漂移崩塌主导机制改判 = **块内路径移动 × 块级自适应的跟踪代价**（"零余量对齐→非因果泄漏"被 S10 消融证伪；官方集发散条这一真·实现缺陷已由 S1 发散防护治愈）。
- 级联 MDF→NN 的真实数据定位（S11）：echo 增益≈NN 且显著优于传统（官方集 + eval_v6）；deg 交易结构照旧；**级联拒评 2/800 须随"生产推荐"话术一并披露**。
- NN deg 差的机理（S5）= **高频带选择性损伤 + 谱平坦化**（非宽带能量压低、非单纯过度抑制）。
