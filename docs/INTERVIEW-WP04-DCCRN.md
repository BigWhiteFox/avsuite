# INTERVIEW — WP-04 DCCRN（模块4）

## 3 分钟讲解提纲

**第 1 分钟：从 CRN 到 DCCRN——为什么要"复数"**
- CRN 用 cRM 输出已经是复数域，但**网络内部**还是实数卷积——处理 Re/Im 两通道
  时没有复数代数结构，相位旋转要靠实数卷积硬拟合
- DCCRN 把卷积/LSTM 全部换成复数版：一次复数乘天然同时处理幅度和相位旋转
  `(W_re+jW_im)(x_re+jx_im)`，参数 ×2 但表达能力覆盖整个复平面
- DNS 2020 冠军方案，论文 PESQ 2.68（WB，DNS 合成测试）

**第 2 分钟：结构与工程参数**
- 编码器 4 层复数卷积 k5 s(2,2)：F 257→17、T 321→21（4s 输入）——时间也降采样
  （与 CRN 不同），LSTM 只需跑 21 步，计算量大减
- flatten 2176 复数维 → 2 层复数 LSTM(64) → FC → 对称解码 + 跳连 → cRM
- 我复现 3.99M 参数（论文 3.71M），17 GMACs/4s；4060 上 batch8×4s ≈1.3s/步

**第 3 分钟：Dynamic Mixing——数据侧的关键**
- 静态数据集：1 万条语音配固定噪声 = 1 万种混合；DM 在线随机配对 = 10000×660
  ×连续 SNR ≈ 数百万种——等效数据量放大百倍，是达标 2.6 的前提（Koizumi 2019）
- 我的实现：SNR U(-5,15)、响度归一 U(-35,-20)dBFS、val 固定 seed 保证曲线可比
- 训练协议：epoch=虚拟长度 1500 次采样（DM 下 epoch 只是采样预算，不是数据集遍历）

## 高频追问预案

**Q1 复数卷积比实数卷积强在哪？给个直觉。**
实数卷积对 Re/Im 两通道独立滤波——它能缩放/混合，但表达"乘 e^{jθ}"（纯相位旋转）
需要两通道间特定的反对称权重耦合，实数卷积要学出这种耦合很费劲。复数卷积
天生带这个结构（W_re x_re − W_im x_im 的交叉项就是旋转）。语音的谐波相位随时间
线性推进（F0 旋转），复数结构直接匹配这个先验。

**Q2 复数 BatchNorm/LayerNorm 怎么做？**
严格版：把 (re,im) 当二维实向量，用 2×2 白化矩阵 + 复数仿射（Trabelsi）。
工程简化：对实数视图 [B,2C,...] 直接 BN（分量各自归一）——离线训练够用，
我的实现即此，README 里明示了与官方复数 LN 的差异。

**Q3 时间维也 stride-2 降采样，流式怎么办？**
DCCRN 原生不友好流式（时间下采样要看未来帧）——所以车载低时延场景后来演化出
GTCRN（WP-05a）：ERB 分组把 F 257→32、时间不降采样、23.7K 参数。这是
"DCCRN 精度 → GTCRN 部署"的技术演进线，面试讲这条线非常加分。

**Q4 为什么损失用复数谱 MSE + SI-SNR 混合？**
谱 MSE 管 T-F 单元级对齐（相位隐含），SI-SNR 管波形级感知（尺度不变）。
单用谱 MSE：低频主导；单用 SI-SNR：谱细节（谐波间噪声）清理不干净。
官方是 SI-SNR + 多分辨率复数谱损——同思想，我的多尺度 STFT loss（WP-02）可换入。

**Q5 DM 为什么有效？和静态增强数据集差多少？**
静态：模型见过 1 万种 (语音,噪声) 组合，测试分布稍有偏移（新噪声类型/SNR 组合）
就掉点。DM：每 epoch 都是新组合，等效无限数据 → 泛化边界收紧。文献与我方消融
（--no-dm）都显示 DM 值 0.2-0.4 PESQ。副作用：训练不可精确复现单 epoch
（我们用固定 seed 的 val 集解决监控问题）。

**Q6 3.99M 参数在 2026 年算什么水平？**
增强模型谱系：DCCRN 3.7M（2020）→ FullSubNet+ ~5M → GTCRN 23.7K（2024，
车载/嵌入式端侧）→ CMGAN/MP-SENet 10M+（离线 SOTA 卷指标）。工程叙事：
"云端离线用大的，端侧实时用 GTCRN 级别；DCCRN 是理解'复数域+掩码'这条主线
的最佳教材"——展示你懂谱系而不是只会一个模型。

**Q7 8GB 显存怎么塞下训练？还能再大吗？**
batch8×4s ≈ 3.0GB（激活为主：257×321 谱图 + 8 层 conv 特征图）。可上 batch 16
（~5.5GB）或 6s 片段；再大就梯度累积。混合精度（AMP）可再省 40%——本项目
未开（复数运算对 fp16 数值范围敏感，谱值动态大，先保稳定）。

**Q8 训练多久收敛？你怎么监控？**
论文级配置 DNS 全量 100+ epoch（A100 天级）。我方子集（10k 语音）+ 压缩模型：
37s/epoch，val 曲线 5-10 epoch 快速下降段 → 40-80 epoch 平台。监控三件套：
TensorBoard val/loss、best.ckpt 按 val 存、history.json 每 epoch 落盘（远程可查）。
early-stop 12 epoch + Plateau 减半 lr。

**Q9 如果 PESQ 只到 2.4（差 0.2 达标）？**
按优先级：① 训练时长（DM 下 loss 还在降就多跑）；② 换回官方通道数 [32,64,128,256]
（显存换指标）；③ 损失换多分辨率复数谱（官方同款）；④ 数据加 RIR 混响增强
（devtest 有 with_reverb 子集）。同时按 WORKLIST 降级路径交付趋势+消融+差距分析。

**Q10 复数 LSTM 和实数 LSTM 差多少参数？为什么不省这里？**
CLSTM 是我方模型参数大头（30%）。省法：hidden 64→32 或用实数 LSTM 吃拼接视图
（DCCRN 官方部分版本即实数 LSTM——复数化的收益主要在卷积层，LSTM 复数化
边际收益小）。我们的消融开关留着这个实验位。

## 必默写公式
- 复数线性：`(W_r+jW_i)(x_r+jx_i) = (W_r x_r − W_i x_i) + j(W_r x_i + W_i x_r)`
- cRM：`Ŝ = M ⊙ X`，M 为网络输出的复数掩码
- SNR 混合：`noise_scale = sqrt(P_clean / (P_noise · 10^{SNR/10}))`
