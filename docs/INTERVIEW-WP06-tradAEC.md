# INTERVIEW — WP-06 传统 AEC（模块6）

## 3 分钟讲解提纲

**第 1 分钟：问题与链路**
- AEC = 从 mic = near + echo + noise 里消掉 echo，且手上只有远端参考 far（电信号）
- echo = far 经过 DAC→功放→扬声器→房间(RIR)→麦克风：线性部分可建模为长 FIR
  （车厢 100-200ms = 1600-3200 taps @16k），于是 AEC 核心 = 自适应系统辨识
- 链路：GCC-PHAT 粗时延对齐（把滤波器长度留给 RIR 而不是纯延迟）→ 自适应滤波
  → DTD 保护近端 → RES 谱减兜底残余

**第 2 分钟：自适应滤波两条路线**
- NLMS：逐样本 w += μ·e·x/||x||²，O(L)/样本；标量归一对语音非平稳稳健
- MDF/PBFDAF：分块频域，FFT 批处理 O(L log L)/块 + 逐 bin 归一（我实测 RTF 0.01
  vs NLMS 0.10，差 10 倍——这就是车载 DSP 全用分块频域的原因）
- 诚实发现：教科书"MDF 收敛快"是对平稳信号；真实语音上逐 bin 白化会被每个音素
  拉着走（||W|| 过拟合到真值 15 倍），稳态反输 NLMS 4-5dB；生产实现
  （speexdsp）靠 prop 逐 bin 梯度加权补差距

**第 3 分钟：DTD——传统 AEC 的灵魂**
- 双讲时误差 e 里混着近端语音，梯度方向被污染 → 不冻结就把近端学进回声路径
  → 消回声变成消自己人（实测无 DTD：NST 近端 PESQ 2.45→1.70）
- 我的三态方案：整段 GCC 峰旁瓣比做回声存在性先验（FEST 19-84 vs NST 4.6-13.4，
  干净可分）→ mic-vs-y_echo 后置相干判双讲（时间对齐无泄漏，WebRTC 同款）→
  ERLE 收敛闩锁防冷启动误判 → DT 软冻结(×0.02)/近端主导硬冻结(=0)

## 高频追问预案

**Q1 ERLE 定义？为什么只统计远端单讲段？（必考）**
ERLE = 10log10(P_mic/P_err)。双讲段 mic 里混近端语音：算进去会把"近端被消掉"
也算成"回声被消掉"——数字虚高且无意义。我们的验收三场景分开：FEST 看 ERLE、
DT/NST 看近端 PESQ（对干净近端参考）。实测无 DTD 配置 FEST ERLE 26.6dB 最好看，
但 NST 近端掉 0.74 PESQ——单看 ERLE 会被骗。

**Q2 Geigel 判据的原理和缺陷？**
假设回声路径衰减 ≥ ERL_floor（如 6dB）：|mic|peak > 0.5·max|far 最近窗| 即判近端
存在。优点零计算；缺陷：假设 ERL 已知且稳定（车载扬声器增益会漂）、对混响尾部
误判、近端比回声弱时（SER<0）漏检。所以工业界都用它做粗判 + 频域判据精判。

**Q3 频域相干性 DTD 为什么算 mic-vs-y 而不是 mic-vs-far？（我的实战坑）**
mic-vs-far 的分段相干被"段内泄漏"压低：分析帧 256 样本 << RIR 1600 taps，帧内
只覆盖 RIR 能量 ~16% → 纯 FEST 相干也只有 ~0.2，阈值没法设。y_echo 是滤波器输出、
与 mic 逐块对齐同带宽 → 无泄漏：FEST 收敛后 γ²→1，双讲 γ²≈P_echo/P_mic 骤降。
这就是 WebRTC AEC suppressor 的结构。

**Q4 收敛前 y≈0，相干判据失效怎么办？（鸡生蛋）**
收敛闩锁：块级 ERLE 的 EMA 连续超 6dB 才启用相干判据；冷启动期用别的证据
（GCC 峰旁瓣比 + mic-far 累积相关）。且闩锁本身要带回声证据门槛——NST 下虚假
相关会"消掉"部分近端造成假 ERLE → 假收敛 → 近端被吃（实测 PESQ 2.45→1.71）。

**Q5 冻结为什么分软/硬两档？**
DT（回声+近端并存）：软冻结 ×0.02——路径还在漂（温度/音量/手持位移），完全冻结
会失锁；近端主导/NST：硬冻结 =0——梯度里根本没有回声信息，任何步长都是纯随机
游走，实测 0.02 步长 8 秒也能积累 40% 量级虚假系数。

**Q6 NLMS 为什么归一化？不除 ||x||² 会怎样？**
LMS 步长稳定界 ∝ 2/(L·P_x)——依赖信号功率，语音功率动态 20dB+，固定步长要么
安静段不收敛要么响亮段发散。归一化后 μ 的物理意义与信号电平解耦（0-2 稳定）。
频域版同理，但要防"过期功率"：我用跨度总功率的慢 EMA + 0.5×瞬时下限，
只用当前块 EMA 会在语音爆发点步长×10 发散（实测 -87dB）。

**Q7 MDF 的梯度约束和系数约束是什么？**
块更新在频域是循环相关，IFFT 后只有前 B 个 lag 是真梯度（后面是卷绕伪影）→
置零（梯度约束）；系数保持 B 点零填充表示，更新后同样截断（系数约束）——
两者保证频域实现与时域 LMS 等价而非"近似"。

**Q8 残余回声从哪来？RES 怎么不伤近端？**
来源：滤波器 misadjustment、路径时变滞后、非线性（功放失真线性滤波根本消不掉）。
RES = 频域 Wiener：G = clip(1−α|Y|/|E|, g_min, 1)，用回声估计 Y 的谱形去压误差谱。
不伤近端靠 DTD 门控：双讲/近端帧 G 强制 1（直通），只在远端单讲帧抑制；
g_min=0.1 地板防"死寂"听感。实测 RES 贡献 FEST +6dB。

**Q9 时延估计为什么用 GCC-PHAT？误差来源？**
语音自相关被谐波结构主导（多峰），PHAT 白化（每频点单位模长）后只剩相位信息 →
峰尖锐。误差来源：无直达径的 RIR（峰落在能量重心，实测偏 26 样本 → 残余路径
非因果 → ERLE 封顶 11dB）；低 SNR；时变时延（蓝牙缓冲抖动）→ 需周期重估。
我同时用峰旁瓣比做回声存在性检测（一石二鸟）。

**Q10 都有 NN-AEC 了为什么还要传统 AEC？（车载岗必考）**
① NN-AEC 的输入特征/监督目标依赖线性 AEC 输出（先线性消 20dB，NN 只学残余——
  微软 AEC-Challenge 冠军方案全是级联）；② 算力：MDF RTF 0.01 在任何 DSP 上跑，
  NN 要 NPU；③ 可解释可调试（每个组件有明确失效模式）；④ 时延估计/双讲检测这些
  状态机逻辑 NN 学不好也不该学。

**Q11 非线性回声怎么处理？（WP-08 入口）**
功放饱和 = 无记忆非线性（soft-clip/tanh 近似）+ 扬声器记忆非线性（悬浮效应）。
路线：Hammerstein（非线性→线性）级联辨识、Volterra 级联、或 NN 功放建模 +
线性滤波联合训练（Ivry 2021）。线性 AEC 在非线性数据上封顶 10-15dB，
这正是合成管道留 soft_clip 开关的原因。

## 必默写公式
- NLMS：`w[n+1] = w[n] + μ·e[n]·x[n]/(||x||²+ε)`
- ERLE：`10·log10(Σmic²/Σerr²)`（远端单讲段、跳收敛瞬态）
- 相干：`γ²(f) = |S_xy|²/(S_xx·S_yy)`
- RES：`G = clip(1 − α·|Ŷ|/|E|, g_min, 1)`，DT 帧 G≡1
